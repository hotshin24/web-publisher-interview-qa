# 웹퍼블리셔 면접 대비 통합 Q&A

웹퍼블리셔 면접 준비를 위한 한·영 기술용어 병기 학습 자료입니다.

## 주요 기능

- 412개 질문·답변 목차와 검색
- 다크·라이트 테마
- 모바일·태블릿 반응형 화면
- 문항별 AI 남성 한국어 음성
- 재생, 일시정지, 속도 조절

기존 기본·기술 면접 문항에 JWA 실제 구현과 HOOT UP AI 산출물 검수 기반 Q299–Q398을 추가했습니다.

## 음성 안내

이 사이트의 음성은 OpenAI 음성 모델로 생성된 AI 음성입니다.

## 이용 범위

개인 면접 학습을 목적으로 제작했습니다.
